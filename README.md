## Assignment overview

This folder contains the three technical-writing exercises and a peer-critique template:

1. `A-user-manual.md` — a beginner-friendly procedure for creating and activating a Python virtual environment in Windows PowerShell and installing a package.
2. `B-api-reference.md` — an API reference for creating a task in a project management application.
3. `C-technical-report.md` — a brief technical report section describing the proposed endpoint and its testing considerations.
4. `D-peer-critique.md` — a structured peer-review worksheet to complete with a classmate.

## How to use these files in VS Code

1. Open the `day5-technical-writing` folder in VS Code.
2. Open each Markdown file from the Explorer panel.
3. Replace the student placeholders in this README.
4. Read through each document and make sure you understand it.
5. For Part A, run the PowerShell commands in the procedure on your own computer if possible. Do not paste the command prompts (`PS C:\...>`)—paste only the commands.
6. Add your own screenshots where indicated, or retain the screenshot descriptions if your instructor only requires descriptions.
7. Complete the peer critique with real feedback from a classmate. Do not claim that a peer reviewed the work if that did not happen.
